Ayuda: POST, GET y redirect

¿Qué es POST?

POST es un método HTTP que permite enviar información al servidor, por ejemplo, los datos de un formulario.

¿Qué es GET?

GET es un método HTTP utilizado para solicitar una página o un recurso al servidor.

¿Para qué sirve redirect()?

redirect() indica al navegador que realice una nueva solicitud a otra ruta. Después de procesar un POST, evita que el formulario vuelva a enviarse al actualizar la página.

¿Por qué request.form queda vacío?

Los datos de request.form pertenecen a la solicitud POST original. La redirección inicia una solicitud GET nueva, que no contiene los datos del formulario anterior.
